# یادروز 🌿

دفتر خصوصی و متن‌باز برای مدیریت تاریخ تولدها و یادبود درگذشتگان، با طراحی فارسی و راست‌به‌چپ.

## ویژگی‌ها

- ثبت، ویرایش، حذف، جست‌وجو و مرتب‌سازی تولدها و یادبودها
- تاریخ هجری شمسی و محاسبهٔ خودکار سن، سال‌های سپری‌شده و مناسبت‌های پیش رو
- نمایش مناسبت‌های سی روز آینده
- حالت روشن و تاریک و طراحی واکنش‌گرا
- پشتیبان‌گیری و بازیابی اطلاعات با JSON
- بدون حساب کاربری، سرویس خارجی، کتابخانهٔ آنلاین یا ارسال اطلاعات به شبکه
- شروع با **پایگاه دادهٔ خالی**؛ هیچ نام یا دادهٔ شخصی در مخزن قرار ندارد

## راه‌اندازی

فایل `index.html` را در مرورگر باز کنید. برای انتشار در GitHub Pages، این سه فایل اصلی را در ریشهٔ مخزن عمومی قرار دهید و در بخش Settings → Pages گزینهٔ Deploy from a branch و شاخهٔ `main` / `(root)` را انتخاب کنید.

## حریم خصوصی

داده‌ها فقط در `localStorage` همان مبدأ وب‌سایت و همان نمایهٔ مرورگر ذخیره می‌شوند. مخزن گیت‌هاب و فایل‌های برنامه هیچ دادهٔ شخصی ندارند. بازدیدکنندهٔ دیگری از سایت، اطلاعات ثبت‌شدهٔ شما را دریافت نمی‌کند. **هر کسی که به همان نمایهٔ مرورگر یا دستگاه دسترسی داشته باشد ممکن است بتواند داده‌ها را مشاهده کند**؛ ذخیره‌سازی محلی رمزگذاری اختصاصی ندارد. پاک‌کردن داده‌های سایت، استفاده از مرورگر دیگر، یا حالت ناشناس می‌تواند باعث ازدست‌رفتن اطلاعات شود. مرتب از قسمت تنظیمات پشتیبان JSON بگیرید و فایل پشتیبان را عمومی منتشر نکنید.

## محدودیت‌ها

- همگام‌سازی بین دستگاه‌ها وجود ندارد.
- برای تبدیل تاریخ از تقویم فارسی داخلی مرورگر (`Intl`) استفاده می‌شود؛ مرورگرهای جدید توصیه می‌شوند.
- برای ورود دستی اطلاعات طراحی شده است؛ هیچ اطلاعاتی از فایل‌های صفحه‌گسترده در پروژه گنجانده نشده است.
